
============
# Encapsulation
=============

Encapsulation in JavaScript is the concept of bundling data (properties) and the methods that operate on that data into a single unit (object or class) while restricting direct access to some of the object's internal details

=========================
# Abstraction in JavaScript
=========================

Abstraction means hiding unnecessary implementation details and showing only the essential features to the user.

JavaScript doesn't have a dedicated abstract keyword like Java or C#. We commonly achieve abstraction using classes, methods, private fields, and closures.

==========================
# Inheritance in JavaScript
==========================

Inheritance is an OOP concept where a child class gets properties and methods from a parent class.

In simple words:

Inheritance = Reusing the properties and methods of another class.

JavaScript mainly uses the prototype chain to implement inheritance, and the class extends syntax provides a convenient way to work with it.

===========================
# Polymorphism in JavaScript
============================

Polymorphism is an OOP concept that means:

"One interface, many forms."

In simple words, the same method name can perform different actions depending on the object that uses it.
