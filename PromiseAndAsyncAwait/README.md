
<!--! Promise in JavaScript -->

A Promise in JavaScript is an object that represents the eventual completion or failure of an asynchronous operation.

In simple words:

Promise = "I will give you a result later."


<!--! Async and Await in JavaScript -->

async and await are used to work with Promises in a cleaner and easier-to-read way.

The main idea is:

async makes a function return a Promise, and await waits for a Promise to settle before continuing that async function.
