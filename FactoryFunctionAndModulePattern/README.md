===============================
# Factory Function in JavaScript
===============================

A Factory Function is a normal JavaScript function that creates and returns objects.

Factory Function = A function that creates and returns objects.

Unlike a constructor function, you don't use the new keyword.

=============================
# Module Pattern in JavaScript
=============================

The Module Pattern is a design pattern used to encapsulate data and functions, keeping some things private while exposing only what is necessary.

Module Pattern = Private data + Public methods

It was commonly used before JavaScript introduced modern ES Modules (import / export).
